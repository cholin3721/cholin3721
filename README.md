### Selected work

#### 01 / [Whisper LoRA for Korean Senior Speech](https://github.com/cholin3721/WHISPER-LoRA)

Fine-tuned Whisper Large v3 with PEFT/LoRA for Korean senior speech. Reduced VOTE400 CER from **20.38% to 10.25%** with only 0.25% trainable parameters.

`Python` `PyTorch` `Transformers` `PEFT`

#### 02 / [Feature-Importance SMOTE](https://github.com/cholin3721/Feature-Importance-SMOTE)

An adaptive oversampling algorithm for extreme class imbalance, combining feature-weighted distance, ADASYN density, and Beta interpolation.

`Python` `scikit-learn` `Imbalanced Learning`

#### 03 / [K-Logistics Simulation](https://github.com/cholin3721/simulation_contest2)

Modeled an 8,858-box fulfillment center and redesigned load balancing, nearest-AGV dispatch, and dynamic pallet slot allocation.

`AnyLogic` `Simulation` `Optimization`

#### 04 / [Autonomous Pallet Sorting Robot](https://github.com/cholin3721/robot_AGV)

A TETRIX PRIZM robot that recognizes pallet QR codes with HuskyLens and autonomously navigates, lifts, and sorts them.

`C++` `Arduino` `Computer Vision` `Robotics`

### How I work

- **Measure before claiming.** I prefer baselines, reproducible experiments, and explicit failure cases.
- **Build across the stack.** Model training, APIs, data contracts, mobile flows, and deployment are one product problem.
- **Design for reality.** Missing data, slow networks, hardware limits, and safety constraints belong in the design—not in the footnotes.
