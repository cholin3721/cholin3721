### 🚀 Featured Projects

#### 🎙 [WHISPER-LoRA](https://github.com/cholin3721/WHISPER-LoRA) — 노인 음성 인식 연구

> Whisper-large-v3에 VOTE400 데이터로 LoRA 파인튜닝.

- 📉 VOTE400 낭독체 CER **20.38% → 10.25%** *(상대 49.7% ↓)*
- 🎯 가장 어려웠던 그룹(JN2): 34.94% → 12.40% *(상대 65% ↓)*
- 🪶 학습 가능 파라미터 **0.25%** (3.9M / 1.55B) — PEFT 효율성 입증
- 🧪 가설 검증: H1(LoRA) ✅ 지지, H2(외부 VAD) ❌ 데이터로 반박
- 🛠 Stack: PyTorch · PEFT · Whisper-large-v3 · 2-GPU DDP

#### 📱 [Recorder-App (이야기봄 春)](https://github.com/cholin3721/Recorder-App) — 노인 구술 AI 각색 앱

> *2026 현대 오토에버 배리어프리 앱 공모전 출품작.*
>
> **"말하기만 하면 된다"** — Zero Learning Curve UX.

- 🎤 1-Button 녹음 → Whisper STT → 무협·로맨스·판타지·역사 소설 각색
- 🧠 위에서 학습한 LoRA 어댑터(19MB)를 STT 백엔드로 직접 활용
- 🤖 Gemini 2.5-flash로 구술→소설 변환, 사용자가 instruction 주면 재생성
- 🛠 Stack: Kotlin · Jetpack Compose · FastAPI · Gemini API · ngrok
